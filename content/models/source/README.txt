This APK includes the editable original.blend, interchange original.glb, exact
conversion source build_ioniq5_model.py and license texts in assets/models/source.
They can be extracted from the APK as an ordinary ZIP. The converted animated
GLB and native mesh are in assets/models. No external download is required to
obtain these source files. The same files are preserved in the project.

Rebuild using standard Python, from this directory:
  python3 build_ioniq5_model.py --source original.glb --output ../rebuilt

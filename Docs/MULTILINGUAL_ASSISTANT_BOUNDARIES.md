# 다국어 어시스턴트 경계

## 구현 범위

UI 언어와 이미 받은 답변의 언어를 분리한다. 완료된 답변은 `answerLocale` 원문 언어를 표시하며, UI 언어를 바꿔도 답변을 새 언어의 답변으로 표시하지 않는다.

번역 요청 대상은 현재 UI 언어이고, 성공한 결과의 대상은 별도 `translationTargetLocale`에 보관한다. 다른 언어를 선택하면 이전 번역 결과·검수 상태·처리 방식·모델 메타데이터와 결과 대상만 지운다. 번역 원문, 입력 초안, 원문 언어·종류와 기존 답변은 유지한다. 같은 언어를 다시 선택하면 완료된 결과를 유지한다. 원문 언어, 요청 대상 언어, 완료된 결과 언어를 각각 표시한다.

동의는 세션 epoch·프로필·UI 언어·화면·번역 종류·원문 언어·원문 초안 및 현재 입력 범위로 한정한다. SDK 갱신과 요청 진행 자체는 동의를 초기화하지 않는다. 처리 중에도 동의를 해제할 수 있으며 로컬 요청 작업과 재전송 스냅샷을 취소한다. 이미 서버로 전송된 처리를 소급 취소하거나 삭제했다는 의미는 아니다. 서버 세션 삭제는 기존 종료·만료·삭제 재시도 정책을 따른다.

언어 선택, 전송, 번역 열기는 화면이 캡처한 scope를 현재 세션·프로필·언어·화면·답변/가이드 문맥과 비교하고, 활성 화면 및 실제 UX의 known·비제한 상태를 다시 확인한다. 오래된 화면의 이벤트는 새 세션의 오류 표시도 변경하지 않는다. 번역 열기는 현재 답변 또는 현재 게시 가이드의 정확한 원문과 판본을 확인한다.

ASK/TRANSLATE에서 다른 화면으로 나갈 때 진행 중 요청과 재전송 스냅샷을 취소한다. 응답은 기존 generation/operation 검사에 더해 현재 scope·세션·활성 상태·UX를 통과해야 한다. 응답 request ID와 실제 응답/번역 대상 언어도 요청과 같아야 화면에 적용한다.

ASK 복귀, 번역 복귀, 언어 선택 복귀의 목적지를 따로 보관한다. `GUIDE → ASK → TRANSLATE → 뒤로 → ASK → 뒤로 → GUIDE`에서 보던 단계와 원문 가이드를 유지한다. 원문 가이드와 UI 언어가 다르면 기존 원문 언어 안내를 유지한다. 가이드 철회 시 모든 복귀 목적지의 해당 가이드를 목록으로 교체하고, 세션 종료 시 복귀 목적지를 초기화한다.

## 검증과 한계

`AssistantBoundaryPolicyTest`는 합성 상태로 언어 변경, 동의 범위, 늦은 이벤트·응답, 현재 원문 확인, request ID/언어 불일치, 중첩 복귀와 철회·종료를 검사한다. SDK·HTTP·모델을 호출하거나 앱에 가짜 차량 값을 넣는 테스트가 아니다. 실제 Pleos SDK 및 모델을 사용하는 native 회귀는 통합 브랜치의 별도 검증으로 기록한다.

검증 명령(오프라인, JDK 17/기존 Android SDK):

```sh
./gradlew testDemoDebugUnitTest --offline --max-workers=2 -PcarcueServerUrl=http://10.0.2.2:8001
python scripts/check_contracts.py
```

최종 JVM 결과는 127개, 실패·오류·건너뜀 0개다. 로그: `output/qa/multilingual-assistant-boundaries-jvm-02.log`. 계약 검사는 191개 UI 리소스와 기존 답변 번들·공식 지원·상태 가이드 규칙을 확인한다.

SDK 수신·UX 판정, 게시 가이드, AI 제공자, 유료 AI 보류와 자유 질문 번역 기본 보류 정책은 이 변경의 대상이 아니다. 기기·모델·실행 중 서버를 이 기능 작업에서 조작하지 않았다.

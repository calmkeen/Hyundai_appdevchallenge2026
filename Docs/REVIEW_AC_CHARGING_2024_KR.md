2026-11-15. 추가 3주제×3언어 중 충전 안내다. 한국시장 NE1/2024, `hyundai-ioniq5-ne1-2024-kr` / `NE1-2024-KR-ko_KR-D202406100040-20240722`를 유지한다. 공식 원문 기반 자체 요약이며 AI 보조 원문·번역 대조다. OEM 승인·인간 전문가/원어민 인증 검수가 아니다.

## 범위

`ioniq5-ac-charging-check` / `charging`: **AC 완속 충전 전 조건과 연결 직후 시작 확인**을 3단계로 제공한다. DC 급속·휴대용 ICCB·V2L·비상 분리·충전 종료/분리의 전체 절차는 다루지 않는다. 각 충전기의 연결/분리 순서와 자세한 조작은 원문 및 충전기 설명서를 우선한다.

1. 의료용 전기 기기 사용자 확인, 방수·물/눈·젖은 손·낙뢰·빗물, 라벨에 맞는 충전기/순정 케이블, 손상·부식·느슨함·연장선·개조/분해 금지.
2. 브레이크 → 주차 브레이크 → 전원 스위치 끔 → P → 시동 끔. 이물질·손잡이·결합 확인, 손/몸 접촉과 케이블 당김·얼어붙은 도어 강제 조작·커넥터 낙하·냉각팬 접촉 금지.
3. 연결 직후 차량/충전기에서 직접 시작 확인, 약1분 표시·예약 시 --·예상 시간 변동과 냄새/연기 등 이상 시 즉시 충전 중지.

CarCue가 충전 상태·전압/전류·차량 장착 케이블을 SDK로 확인한 결과가 아니다. 관련 property와 상태 재조회 action은 비워 두며 공식 원문 열기만 제공한다. 충전 제어 API를 추가하지 않는다.

## 번역·게시 검증

한국어 원문 요약의 순서·조건·부정·위험과 영어·일본어 요약을 독립 대조한 뒤 게시한다. UI 언어를 바꿔도 KR 판매사양과 한국어 공식 원문 범위는 유지한다. 전체 body·모든 단계 본문·모든 명시 주의문은 AI에서 하나의 완전 단위로 조립하며 3000자 상한을 유지한다. 문 안내의 기존 주의문/핀은 변경하지 않는다.

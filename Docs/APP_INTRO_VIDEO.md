# CarCue 앱 소개 영상

2026-11-13. 사용자 요청에 따라 실제 앱 화면을 소개용 이야기와 자막·배경음악으로 구성했다. 결과는 `output/qa/carcue-app-intro.mp4`다. 32초, 1920×1080, 16:9, 30fps이며 일반 기능 장면은 2초씩 보여준다.

## 구성

| 시간 | 메시지 | 실제 화면 |
| --- | --- | --- |
| 0–3초 | CarCue · 낯선 차도, 내 언어로 편하게 | 브랜드 시작 카드 |
| 3–7초 | 내 차량에 맞춰 시작하세요 | 차량 확인, 한국어·영어·일본어 선택 |
| 7–11초 | 지금 받은 상태를 한눈에 | 문 열림·닫힘 시연과 수신 정보 |
| 11–13초 | 실제 차량을 보며 확인하세요 | 앱 내 IONIQ 5 실차 참고사진 |
| 13–17초 | 사진과 함께 단계별로 | 가이드 목록과 사진이 있는 단계 |
| 17–19초 | 궁금한 순간, 바로 질문 | 가이드에서 이어지는 질문 화면 |
| 19–27초 | 익숙한 언어로 이어지는 경험 | 영어 선택·화면, 일본어 선택·화면 |
| 27–29초 | 이용이 끝나면 가볍게 마무리 | 이용 종료 확인과 초기화 |
| 29–32초 | CarCue · 낯선 차를 더 익숙하게 | 브랜드 마무리 카드 |

실제 앱 화면을 오른쪽에 크게 두고 왼쪽에 기능 제목·설명을 표시한다. 앱 화면 전체를 유지해 Mock 표시를 가리지 않는다. 시작 카드는 CC0 실차 사진과 브랜드 문구를 사용하며 기능 화면과 구분한다. 짧은 전환과 진행 표시를 사용한다.

## 원본·동작 구분

모든 기능 장면은 `carcue-native-run.mp4`에서 가져왔다. 해당 원본은 전달 APK와 설치 APK의 해시가 일치한 하나의 실제 앱 실행 녹화다. 앱 안에서 3D·사진·언어 선택이 실제로 동작한다. 소개 영상에서는 다른 앱의 3D나 별도 참고 사진 장면을 기능 화면에 끼워 넣지 않는다.

차량값은 demo의 MOCK이다. 사진·모형은 설명용이며 검수된 차종별 조작 매뉴얼을 뜻하지 않는다. AI 질문 장면에는 ‘AI 답변 연결 준비 중’을 표시한다. 실제 AI 응답 생성이나 실차 수신을 완료한 것처럼 소개하지 않는다. 실차 사진을 기본으로 표시하도록 앱을 바꾸고 새 APK를 빌드·재촬영했다.

## 배경음악과 차량 사진

현재 음악은 **Scott Buckley의 A Kind Of Hope** 원곡 다운로드다. 원작자의 CC BY 4.0 조건을 확인하고 영상에 출처 표기를 넣었다. 원곡 12초 지점부터 32초를 사용하고 음량·페이드를 조정한다. 음악을 합성하는 코드는 제거했다. 출처·조건과 게시용 표기는 `MEDIA_CREDITS.md`, 파일 해시는 `media-sources.json`을 따른다.

차량의 기본 화면과 시작 카드에는 CC0로 공개된 실제 IONIQ 5 사진을 사용한다. IONIQ 5 N을 선택하면 N 사진으로 바뀐다. 기존 일반 3D 모형은 앱의 보조 ‘3D 위치 예시’ 탭에 남겨 두고 현재 소개 영상은 실차 사진을 중심으로 구성한다. 충전 가이드 사진은 인계 ZIP의 기존 이미지이며 별도 출처로 관리한다.

## 재현·검증

macOS/Xcode와 보존된 실제 앱 원본 녹화가 있는 환경에서 실행한다.

```bash
python3 scripts/render_app_intro.py
```

`app-intro.json`에서 자막·시간·원본 구간을 관리한다. `render_app_intro.swift`가 AVFoundation으로 시작 카드·실제 영상·자막·음악을 합성한다. 같은 이름의 결과 JSON에 원본·APK·계획·출력 해시를 기록한다. 실행 녹화 원본은 수정하지 않는다.

모든 15개 장면의 중앙 프레임을 디코딩해 시작·자막·실차 사진·가이드·질문 준비 중 표시·일본어·마무리를 육안 확인했다. `app-intro-video-check.txt`와 `app-intro-frames/`에 결과가 있다. 완성된 MP4의 AAC를 실제로 디코딩해 32초·무음 아님·클리핑 없음도 확인한다. 오디오 검사 결과는 `app-intro-audio-check.json`에 저장한다.

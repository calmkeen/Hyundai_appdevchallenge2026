## 실제 동작과 Mock의 구분

- **실제 앱 기능:** 네이티브 화면 이동, 언어 카탈로그 검색·선택, 차량 프로필 변경 시 문맥 삭제, 가이드 단계 복귀, 오류 표시, 로컬 세션 종료, API 클라이언트.
- **실제 서버 기능:** HTTP API, 세션 토큰 소유 검사, 만료·삭제, 요청 중복 방지, 프로필/버전/검수 상태에 따른 검색, 출처 ID 대조, 원문 추출 검증, 요청 제한.
- **실제 UX 제한 API:** 초기 GET false/0, 주행 조건 callback true/80, 주차 복귀 callback false/0을 전용 AVD에서 확인했다.
- **실제 SDK 데이터:** `pleos` flavor에서 전용 AVD의 문 상태 Capability·GET·변경 콜백을 수신했다. 실차 값이 아니라 전용 AVD가 제공한 값이다.
- **MOCK 차량 데이터:** `demo` flavor의 모든 문 상태. 주차/제한 시나리오도 Mock이며 실제 CarUxRestrictions 수신이 아니다. APK·화면에 MOCK을 표시한다.
- **MOCK AI:** 기본 서버는 답을 생성하지 않고 `NO_RELIABLE_SOURCE` 또는 번역 불가를 반환한다. `mode=MOCK`가 표시된다.
- **OpenAI LIVE 어댑터:** 구현 및 HTTP transport 대역 테스트만 수행했다. 실제 API 키·모델 설정과 호출 증거는 없다. 초기 답변은 검수 원문의 직접 추출로 제한하며 자유 생성 조작 설명은 제공하지 않는다.
- **가이드 시연:** Mock 전용 화면 탐색 예시다. 실제 차량 매뉴얼이 아니며 조작 절차를 담지 않는다. 인계 템플릿은 `DRAFT` 상태로 비게시한다.
- **앱 내 이미지·3D:** 네이티브 Compose의 일반 차량 3D 위치 모형·드래그 회전·상태별 문 표시와 실제 Image 컴포넌트의 가이드 사진을 구현했다. 모형은 차종의 정확한 외형을 뜻하지 않는다. `NATIVE_VISUALS.md` 참조. demo 값은 MOCK, pleos 수신 어댑터는 기존 SDK 연결을 유지한다.
- **실제 실행 영상:** 최신 촬영은 동일 APK의 연속 실행 화면을 사용한다. 이전의 참고 이미지·Pleos 시스템 3D를 붙인 편집본은 이 실행 증거와 별도로 보존한다. 구성은 `VIDEO_STORYBOARD.md`에서 관리한다.
- **프로필:** 두 개발용 프로필 모두 UNVERIFIED다. 차종 일치, 매뉴얼 버전, 옵션, 공식 지원 연락처 검수가 필요하다.

`mode=LIVE`는 서버 처리 모드이며 차량 데이터의 진위를 보증하지 않는다. 각 값의 `source=PLEOS/MOCK`를 따로 표시한다.

## Mock 언어 범위 변경 · 2026-11-13

사용자 요청에 따라 Mock 선택 목록을 `ko-KR`, `en`, `ja-JP`로 제한했다. `catalog.json`의 `mock_visible`로 목록을 관리하며 48개 후보와 RTL 확장 구조는 보존한다. 일본어 UI 초안과 서버의 자료 부족·일시 불가 고정 응답을 추가했다. 언어 변경은 판매지역·차량 사양이나 이미 열린 가이드의 원문을 바꾸지 않는다. 일본어를 포함한 모든 차량 가이드의 검수 상태는 여전히 PLANNED이며, OpenAI 실제 호출을 추가한 작업은 아니다.

넓은 시연 화면은 차량 디스플레이를 재현하는 Pleos 전용 AVD 환경이다. 실제 SDK 검증 환경은 2560×1440이며, Mock 회귀 환경은 1280×800이다. 일반 Android 기기에서 실행 가능한 demo 빌드와 차량용 SDK를 사용하는 pleos 빌드를 구분한다.

## 아직 완료되지 않은 제품 요구

1. 실차·다른 영역·차종의 수신과 다른 지역 UX 정책 검증.
2. 정확한 차종·연식·판매지역·옵션별 공식 매뉴얼과 이용 조건 검수. 문 안내와 충전/좌석·거울/화면·표시등의 게시 가능한 콘텐츠.
3. OpenAI 실제 호출, 다국어 번역의 의미·부정·순서·부품명 검수. 숫자 비교나 출처 대조만으로 번역 품질을 보증하지 않는다.
4. 검수 자료의 로컬 영구 캐시는 프로필·매뉴얼 버전·언어 키로 구현했다. 실제 게시 콘텐츠와 오프라인 기본 안내 묶음은 아직 없어 해당 콘텐츠의 현장 시연은 미검증이다.
5. ROW_1_LEFT / 0..1의 OPEN/CLOSED는 전용 AVD에서 확인했다. 다른 범위의 의미 검증과 검수 매뉴얼 기반 상태별 가이드 규칙 등록은 남아 있다.
6. 공식 매뉴얼/지원 자료가 등록된 뒤 관련 링크·후속 action의 실제 전체 흐름 검증.
7. 일반 폰에서 QR 카메라 스캔 후 안내 웹/앱 진입. 현재 검증 범위는 차량 앱의 제한된 프로필 딥링크 처리이며 인증 페어링은 아님.
8. 실제 Pleos 디스플레이의 터치·초점·로터리·접근성·지역별 UX 제한. 일반 AVD 검증과 구분한다.

여행·내비·음성·차량 제어·인증 폰 연결·외부 배포·공모전 제출은 수행하지 않았다.

# 기획 개요: 다국어 차량 이용 가이드

상태: 사용자 방향 반영 / 2026-11-12 / 제품명·초기 차종·시장 검증 미완료

## 한 문장
처음에는 짧게 차량 이용법을 익히고, 이후 궁금하거나 문제가 생겼을 때 자신의 언어로 상태별 안내를 다시 확인하며 필요하면 현지 직원에게 상황을 보여주는 Pleos 차량 이용 가이드.

## 중심과 부가 기능
- 중심: 첫 탑승 안내 → 필요할 때 상태·사용법 확인 → 해결되지 않으면 직원 도움.
- 부가: 여행 목록·관광지·음식점·일정 추천. 핵심 안내가 완성되기 전에는 구현하지 않는다.
- 번역 앱이나 새 내비가 아니라 낯선 차의 반복적인 사용 안내를 돕는 것이 목표다.
- 직원 반복 설명 시간 절감은 앞으로 측정할 가설이며 확보된 효과가 아니다.

## 대상 가설
한국 방문 외국인 렌터카 이용자를 초기 시나리오로 삼되, 실제 Pleos 탑재 렌터카 보급과 도입 수요는 미확인이다. 이후 해외 판매 차량의 첫 사용자로 확장할 수 있으나 OEM 출고 탑재는 계약·심사·검증이 필요한 별도 경로다.

## 구현 원칙
한 차종·한국어/영어·검수 안내 3개·실제 읽은 상태 1개·직원에게 보여줄 양언어 도움 카드를 우선 제안한다. 도움 카드는 사용자가 확인한 질문과 실제 수신값을 구분하며 자동 진단이나 자동 전송을 하지 않는다.
QR 정적 안내 링크와 인증된 폰-차량 연결은 다르다. 앱 언어 변경과 차량 시스템 언어 변경도 다르다. AI 상담은 후속 검증 대상이다.

## 차별화 가설
Gleo의 매뉴얼 안내와 기존 매뉴얼·번역 기능을 인정한다. 차별화 후보는 일회 설명 이후 다시 찾는 상황별 안내와 현지 직원에게 전달할 도움 카드의 연결이다. 실제 편의성과 직원 시간 절감은 비교 과제로 검증한다.

상세 범위와 판단 기준은 [제품 기획안](07-product-plan.md), 실제 API 상태는 [SDK 검증 기록](03-sdk-verification.md)을 따른다.

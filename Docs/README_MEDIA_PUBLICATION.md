# README 소개 영상과 브랜치 안내

2026-11-15. 사용자가 기존 소개 영상의 GitHub README 추가와 main의 develop 이동 안내를 요청했다. 기존 로컬 개발용 출처 기록 이후의 현재 공개 연결 요청으로 구분한다. 영상 편집·앱 코드·APK·제출 후보는 갱신하지 않는다.

- develop은 `media/intro/`에 MP4·기존 시작 PNG·크레딧의 동일 사본과 SHA manifest를 두고 README 상단에서 연결한다.
- main은 별도 main 기반 작업 브랜치의 README 한 파일만 반영한다. 현재 개발·설치·실행 문서는 develop 링크를 사용하며 전체 develop 코드를 main으로 병합하지 않는다.
- main의 이미지·영상·크레딧 링크도 공개 develop 경로를 사용해 존재하지 않는 main 상대 파일을 가리키지 않는다.
- 영상은 기존 SDK debug 검증본, 실제 AVD·무료 모델 선택·저장 번역 기록이다. 새 release와 동일 바이너리·실차·Mock 영상으로 표현하지 않는다.
- 음악의 곡명·작가·CC BY 4.0·원문 링크를 양쪽 README와 사본 크레딧에 유지한다. Pleos 시각 자료의 별도 재배포 허가는 새로 확인하지 않았으며 사용자 요청을 그래픽 라이선스 취득으로 표시하지 않는다.

원본 MP4 SHA256은 `638c1f54d3e29ddba3212154c118267bcfc8be21a3dda0ad004066f3e600e18d`다. 새 공개 사본도 같은 값이다. 기획서 개인정보·세션 로그·원시 녹화·서명키는 올리지 않는다. 작업별 링크·내용·차이·원격 반영을 확인하고 develop CI와 실제 GitHub README 표시를 검증한다. main에는 워크플로가 없어 README 내용/링크 검증과 원격 차이 확인으로 구분한다.

실제 공개 feature의 GitHub MP4 파일 페이지는 크기 제한으로 미리보기를 제공하지 않았다. Playwright 로컬에서 `View raw`를 클릭해 원본 다운로드 시작을 확인했으며, 두 README의 썸네일·영상 버튼을 이 직접 다운로드 URL로 연결한다. 인라인 플레이어로 표시하거나 원본을 재인코딩하지 않는다.

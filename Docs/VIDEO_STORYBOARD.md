# CarCue 영상 구성

최신 소개 영상은 **`output/qa/carcue-app-intro.mp4`**다. 실제 APK 녹화를 바탕으로 시작·기능 설명·언어 전환·마무리를 구성한 34초 소개용 편집본이다. 자막과 배경음악이 있으며 일반 기능 장면은 2초다. 기획·출처·재현 방법은 `APP_INTRO_VIDEO.md`, 편집 구간은 `app-intro.json`을 따른다. 기본 `carcue-mock-flow.mp4`도 이 소개 영상으로 갱신한다.

## 실제 앱 실행 원본

2026-11-13. 최신 기준은 새 APK를 실행한 화면의 연속 녹화다. IONIQ 5 스타일 3D와 가이드 이미지가 APK 내부에서 표시되고 실제 버튼·드래그·언어 변경으로 진행한다. 3D가 기본 화면이며 기존 사진은 보조 탭으로 보존한다.

결과는 `output/qa/carcue-native-run.mp4`, 증거는 같은 이름의 JSON과 `native-showcase-instrumentation.txt`다. 기능별 화면은 2초씩 유지하며 실제 터치와 전환 시간이 포함된다. 앱 외부의 사진·3D·다른 화면을 후처리로 삽입하지 않는다. 차량 데이터는 demo의 MOCK이며 실제 AI를 호출하지 않는다.

## 재현

부팅된 테스트 AVD와 최신 demo·기기 테스트 APK를 준비한 뒤 실행한다.

```bash
python3 scripts/record_native_showcase.py
```

설치된 APK의 해시를 전달 APK와 대조하며, 앱이 준비된 뒤 녹화를 시작하고 마지막 화면이 유지되는 동안 녹화를 마친다. 이 원본은 `carcue-native-run.mp4`로 보존하며 소개 영상의 실제 기능 장면에 사용한다.

이전 28초·32초 편집본과 무편집 언어 전환 영상은 원래 파일명으로 보존했다. 이전 편집 구성은 `history/VIDEO_STORYBOARD_EDITED.md`, `video-short.json`과 `render_mock_short.py`로 재현할 수 있다. 최신 실제 앱 실행 영상과 별도 결과다.

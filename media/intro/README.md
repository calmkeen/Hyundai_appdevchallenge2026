# CarCue 소개 영상

`carcue-sdk-intro.mp4`는 검증된 기존 34초 소개 영상의 바이트 동일 사본이다. `intro.png`도 당시 편집본의 기존 시작 프레임이다. 원본 영상·음악·설정·촬영 증거와 제출 APK는 변경하지 않았다. 파일 크기와 SHA256은 `manifest.json`, 음악 표기는 `CREDITS.txt`를 따른다.

영상은 한 Pleos SDK debug APK/프로세스의 실제 전용 AVD 연속 녹화에서 편집했다. 새 0.1.1-rc1 release와 같은 바이너리는 아니며, 실차나 새 안내9개·미완료 경계 시험의 증거가 아니다. 유료 AI를 호출하지 않았고, 문 안내의 실제 무료 로컬 모델 선택과 저장 번역을 구분한다.
